**JYOMARG** is a futuristic, hybrid AI-powered career and learning ecosystem. It bridges the gap between academic learning and industry requirements using a state-of-the-art **Hybrid AI Architecture** that combines deterministic Python logic with Large Language Model (LLM) reasoning.

### 🌐 Live Application: [https://jyomarg-1.onrender.com](https://jyomarg-1.onrender.com)

---

## 🚀 Key Modules

### 🤖 ABHI Core (Architecting Better Human Intelligence)
Your real-time AI companion. It uses a **Hybrid Router** to determine if a question requires a simple logic-based answer or complex LLM reasoning, ensuring fast and accurate career guidance.

### 📚 LEARN & COURSE Module
Dynamic "Basics to Advanced" curriculum generation.
- **Hybrid Syllabus**: Python enforces rigid course structure and numbering while the LLM injects high-quality technical content.
- **Progressive Lessons**: Daily lessons generated on-the-fly with integrated assessments.

### 📄 Resume Architect & Hybrid ATS
A production-grade resume analysis system.
- **Deterministic Scoring**: Unlike pure LLM systems, JYOMARG uses Python-based math to calculate scores (Skill Match, Experience Weight, etc.) while using AI to provide meaningful feedback and suggestions.
- **Parsing**: Advanced extraction from PDF and text-based documents.

### 🔍 Skill Analyzer & Gap Report
Detailed comparison between your current profile and job descriptions. It generates a "Gap analysis" highlighting exactly what skills you need to acquire to land your dream job.

### 🗺️ Career Roadmap
Strategic paths generated by AI with flawlessly enforced global numbering across phases, ensuring the learner never loses their way.

## ✨ Features & Architecture

- **🧠 Hybrid AI Engine**: Moves away from monolithic API dependency. Uses Python to handle data structure, validation, and scoring, while the LLM (Gemini) handles creativity and interpretation.
- **💎 Premium UI/UX**: Immersive "Deep Space Cyberpunk" design system using transparent glassmorphism, glowing neon accents, and smooth CSS transitions.
- **⚡ Advanced Caching**: Local caching of AI responses to minimize API costs and provide lightning-fast interactions.
- **🛡️ Secure Sessions**: Uses `itsdangerous` for encrypted session management and `pydantic` for strict data validation.
- **📊 Real-time Analytics**: Tracks user progress, assessment scores, and skill improvements dynamically.

## 🛠️ Technology Stack & Tools

### **Backend & Core**
- **Python**: The core logic engine.
- **FastAPI / Uvicorn**: High-performance asynchronous web framework.
- **Pydantic**: Data modeling and strict JSON validation.
- **Jinja2**: Dynamic HTML template rendering.

### **AI & Intelligence**
- **Google Gemini API (Pro/Flash)**: Primary reasoning engine.
- **Hybrid Orchestration**: Custom-built logic in `/services` and `/ai` directories to manage prompt routing and output validation.
- **Deterministic Logic**: Math-heavy ranking and scoring systems written in pure Python.

### **Data & Storage**
- **SQLite / PostgreSQL**: Multi-database support with `psycopg2`.
- **PyPDF2**: Structured text extraction from resume uploads.
- **Custom Cache**: Efficient database-backed response storage.

### **Frontend Aesthetics**
- **Vanilla CSS3**: Custom design tokens, glassmorphism, and neon animations.
- **Anime.js / Marked.js**: Dynamic UI animations and Markdown-to-HTML rendering for AI responses.
- **Font-Awesome / Google Fonts**: Modern typography and iconography.

## 💻 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/AbhilashNelapati/JYOMARG.git
   cd JYOMARG
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment Variables**
   Create a `.env` file in the root directory:
   ```env
   GOOGLE_API_KEY=your_gemini_api_key_here
   SECRET_KEY=your_random_secret_key
   PORT=9000
   ```

4. **Initialize Database**
   The application initializes the database automatically on the first run.

5. **Run the Application**
   ```bash
   python app.py
   ```
   The server will start on `http://127.0.0.1:9000`
